# DIAL-BAM Method

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**DIAL** (Discovery → Insight → Architecture → Launch) + **BAM** (BMAD + Architecture Method) — A product and startup methodology for AI tools and Vibe coding.

Covers the full chain: **industry analysis → demand research → solution refinement → digital tooling → short/mid/long-term planning → task breakdown**. Integrates BMAD, business architecture, YiTang Five Steps, and Lean Startup.

100% free and open source.

---

## Why DIAL-BAM?

Traditional approaches often separate demand analysis, business architecture, and delivery. DIAL-BAM unifies:

- **DIAL**: Full flow from discovery to task breakdown, hypothesis-driven
- **BAM**: Traceable mapping: REQ ↔ L1 ↔ L2 ↔ Epic ↔ Story ↔ L3 ↔ L4

## Quick Start

### Option 1: Copy to project

```bash
git clone https://github.com/YOUR_USERNAME/dial-bam-method.git
cp -r dial-bam-method/docs dial-bam-method/tools your-project/documents/
```

### Option 2: npm init

```bash
npx dial-bam-method init
```

Copies files to `documents/` in the current directory.
