## 二、「完整交付件」定义

**最小完整**：具备可追溯链的 BAM JSON，含 L1、L2、L3、L4、REQ、Epic、Story。

**推荐完整**：四阶段均有工具产出，且可关联：
- 洞察 + 痛点 → BAM 初稿
- BAM → 规划看板
- 规划看板 → BML 关联 Epic/Story

**全量完整**：上述 + Project Brief、PRD（使用 Project Brief 工具、PRD 模板工具）。
