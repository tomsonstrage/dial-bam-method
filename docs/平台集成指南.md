## 一、导出格式与平台适配

### 1.1 当前导出能力

| 工具 | 导出格式 | 用途 |
|------|----------|------|
| 洞察可视化 | JSON、TXT | 可复制到飞书文档、Notion |
| 痛点画布 | JSON、TXT | 同上 |
| 商业模式画布 | JSON、TXT | 同上 |
| Project Brief | JSON、MD | MD 可直接粘贴 |
| PRD 模板 | JSON、MD | 同上 |
| BAM 追溯矩阵 | JSON、Excel | Excel 可导入飞书多维表格、Notion 数据库 |
| 规划看板 | JSON、Excel | 同上 |
| 交付包导出 | JSON、MD | 完整汇总 |

### 1.2 飞书适配

**多维表格**：BAM、规划看板导出 Excel 后，可导入飞书多维表格。

| 步骤 | 操作 |
|------|------|
| 1 | 在 BAM 追溯矩阵或规划看板点击「导出 JSON」或使用 Excel 导入后导出 |
| 2 | 飞书多维表格 → 导入 → 从 Excel 上传 |
| 3 | 按列映射：L1、L2、REQ、Epic、Story 等 |

**文档**：交付包「导出 Markdown 汇总」生成的 MD 可复制到飞书文档。

### 1.3 Notion 适配

**数据库**：Excel 导入 Notion 数据库，或手动建表后按 JSON 结构录入。

| DIAL-BAM 结构 | Notion 属性建议 |
|---------------|-----------------|
| L1 | 单选/多选 |
| L2 | 单选，关联 L1 |
| REQ | 文本，关联 L1/L2/Epic |
| Epic | 文本，关联 L2 |
| Story | 文本，关联 Epic |

**页面**：Project Brief、PRD 的 MD 导出可粘贴为 Notion 页面内容。

## 二、与 BMAD 的衔接

### 2.1 数据流

```
DIAL-BAM（规划层）          BMAD（执行层）
─────────────────          ─────────────────
洞察、痛点、Project Brief  →  BMAD Phase 1 输入
BAM L1/L2/REQ/Epic/Story  →  BMAD Analyst/PM Agent 上下文
规划看板 Epic/Story        →  BMAD Scrum Master Agent Story 拆解
BML 验证记录               →  迭代复盘、坚持/转向决策
```

### 2.2 字段映射

| DIAL-BAM | BMAD 对应 |
|----------|-----------|
| L1 业务域 | 业务上下文、领域划分 |
| L2 模块 | 功能模块、Epic 划分 |
| REQ | 需求条目、User Story 来源 |
| Epic | BMAD Epic |
| Story | BMAD Story、Context-Engineered Story |
| L3/L4 | 验收标准、AC |

### 2.3 使用方式

1. **先 DIAL-BAM**：完成 Discovery→Insight→Architecture，产出 BAM JSON
2. **导出 BAM**：从 BAM 追溯矩阵导出 JSON
3. **输入 BMAD**：将 BAM 的 Epic/Story 结构作为 BMAD Agent 的上下文输入
4. **BMAD 执行**：Analyst/PM/Architect Agent 基于 BAM 产出 PRD、架构、开发 Story

详见 [与BMAD的关系](与BMAD的关系.md)。
