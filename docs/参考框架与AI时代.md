# 参考框架与 AI 时代

> DIAL-BAM 组合的参考框架汇总，及 AI 时代的方法论变化。

---

## 一、参考框架总览

| 阶段 | 框架 | 组织/来源 | 用途 |
|------|------|-----------|------|
| **洞察** | PESTEL | 战略管理 | 宏观环境（政治、经济、社会、技术、环境、法律） |
| **洞察** | 波特五力 | Michael Porter | 竞争分析（同业、供应商、购买者、替代品、新进入者） |
| **洞察** | SWOT | 战略管理 | 内外部综合（优势、劣势、机会、威胁） |
| **战略** | 战略地图 | Kaplan & Norton | 目标拆解、平衡计分卡 |
| **战略** | 商业模式画布 | Osterwalder | 客户、价值、渠道、收入、成本等 9 模块 |
| **业务架构** | BIZBOK | Business Architecture Guild | 能力地图、价值流、举措地图等 9 类蓝图 |
| **企业架构** | TOGAF | The Open Group | 业务→应用→数据→技术架构，ADM 流程 |
| **业务分析** | BABOK | IIBA | 需求分析、启发、变更、解决方案评估 |
| **数字化转型** | MIT 九要素 | MIT Sloan | 客户体验、运营流程、商业模式三领域 |
| **开发** | BMAD | BMad Code | AI 驱动敏捷开发、Agent 协作 |

---

## 二、框架与 DIAL-BAM 映射

```
洞察层：PESTEL + 波特五力 + SWOT
    ↓
战略层：战略地图 + 商业模式画布
    ↓
业务需求：运营提效 / 新增业务（BABOK、MIT 九要素）
    ↓
业务架构：L1/L2/L3/L4（BIZBOK、TOGAF）
    ↓
数字化交付：Epic/Story/Task（BMAD、精益 BML）
```

## 三、AI 时代的不同

### 3.1 洞察与战略

| 传统 | AI 时代 |
|------|---------|
| 人工搜集 PESTEL 数据 | AI 爬取、摘要、多源对比 |
| 人工竞品调研 | AI 自动监测、功能对比、舆情分析 |
| 研讨会产出 SWOT | AI 基于输入生成初稿、多方案 |
| 手写商业模式画布 | AI 生成初稿、行业对标、变体探索 |

### 3.2 业务需求与架构

| 传统 | AI 时代 |
|------|---------|
| 需求会逐条拆解 | AI 从 PRD 生成 REQ/Epic/Story 初稿 |
| 人工维护追溯 | AI 辅助影响分析、依赖推荐 |
| 架构师画图 | AI 辅助生成架构图、技术选型 |
| 需求会拆 Task | AI 从 Story + L3 生成 Task 列表 |

### 3.3 交付与迭代

| 传统 | AI 时代 |
|------|---------|
| 手写代码 | Vibe coding、Cursor、Copilot |
| 人工写 PRD/AC | AI 辅助起草、迭代 |
| 人工分析 BML 数据 | AI 总结、建议坚持/转向 |
| 单人/小团队 | Agent 协作（Analyst、PM、Architect 等） |

### 3.4 核心变化

- **速度**：洞察→交付周期缩短
- **成本**：信息搜集、初稿生成成本下降
- **人机分工**：人决策、AI 生成与执行
- **结构化上下文**：L1/L2/L3/L4、追溯矩阵让 AI 更懂业务
- **风险**：需验证 AI 产出、避免幻觉
