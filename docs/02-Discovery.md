## 一、五维洞察

**参考框架**：PESTEL、波特五力、SWOT

| 维度 | 关注点 | 参考 | 产出 |
|------|--------|------|------|
| **行业** | 产业链、价值链、政策、周期 | PESTEL | 行业地图、机会与约束 |
| **社会** | 人口、消费、文化、趋势 | PESTEL-Social | 社会趋势、需求演变 |
| **技术** | 成熟度、成本、替代性 | PESTEL-Technological | 技术可行性、技术路线 |
| **竞争** | 对手、替代品、新进入者 | 波特五力 | 竞争格局、差异化空间 |
| **内部** | 能力、资源、组织、文化 | SWOT（S/W） | 能力画像、资源约束 |

**PESTEL**：Political, Economic, Social, Technological, Environmental, Legal  
**波特五力**：同业竞争、供应商议价、购买者议价、替代品威胁、新进入者威胁  
**SWOT**：Strengths, Weaknesses, Opportunities, Threats

### 1.1 五维洞察细化

| 维度 | 子项 | 关键问题 | 产出格式 |
|------|------|----------|----------|
| **行业** | 产业链 | 上下游是谁？价值如何分配？ | 产业链图、价值链分析 |
| | 政策 | 监管、补贴、准入？ | 政策清单、影响评估 |
| | 周期 | 行业所处阶段？ | 生命周期判断 |
| **社会** | 人口 | 目标用户画像？ | 人口结构、消费趋势 |
| | 文化 | 消费习惯、偏好？ | 文化因素清单 |
| **技术** | 成熟度 | 技术是否可用？成本？ | 技术成熟度曲线 |
| | 替代性 | 新技术替代风险？ | 技术路线图 |
| **竞争** | 五力 | 各力量强弱？ | 五力评分、竞争格局图 |
| **内部** | SWOT | S/W/O/T 各 3–5 条 | SWOT 矩阵 |

### 1.2 执行步骤

1. 搜集 PESTEL 各维度资料（政策、报告、数据）
2. 填写波特五力（可用 [洞察可视化](../tools/洞察可视化.html)）
3. 内部研讨产出 SWOT
4. 汇总为洞察报告，标注机会与约束

## 二、战略规划

**参考框架**：战略地图、商业模式画布

| 输入 | 战略输出 |
|------|----------|
| 行业 + 社会 | 目标市场、业务方向、价值主张 |
| 技术 + 竞争 | 差异化路径、技术路线、能力建设 |
| 内部 | 资源配置、节奏、取舍 |

**商业模式画布**：客户细分、价值主张、渠道、客户关系、收入来源、核心资源、关键活动、关键合作、成本结构

### 2.1 战略规划步骤

1. **输入整合**：将五维洞察结论汇总
2. **目标市场**：明确 TAM/SAM/SOM，选定细分
3. **价值主张**：一句话说明「为谁解决什么问题」
4. **差异化**：与竞品的 3 个核心差异
5. **资源配置**：人力、预算、节奏

## 四、需求调研（痛频量价）

**参考**：一堂「需求里程碑」、精益「价值假设」

| 验证维度 | 一堂四字诀 | 验证方式 |
|----------|------------|----------|
| **痛** | 需求强度 | 用户访谈、痛点排序 |
| **频** | 发生频率 | 行为数据、问卷 |
| **量** | 用户规模 | 市场估算、TAM/SAM/SOM |
| **价** | 付费意愿 | 预付费测试、定价实验 |

### 4.1 痛频量价验证步骤

1. **痛**：用户访谈 5–10 人，痛点排序，确认「是否真痛」
2. **频**：行为数据或问卷，确认使用频率（日/周/月）
3. **量**：TAM（总市场）→ SAM（可服务）→ SOM（可获取）
4. **价**：预付费/众筹测试，或定价实验

### 4.2 需求假设清单模板

| ID | 假设 | 验证方式 | 状态 |
|----|------|----------|------|
| H1 | 用户愿意为 X 付费 | 预付费测试 | 待验证 |
| H2 | 月活可达 Y | 小范围投放 | 已验证 |

## 五、产出与 BAM 衔接

| 产出 | 说明 |
|------|------|
| 洞察报告（五维） | 行业、社会、技术、竞争、内部 |
| 战略规划要点 | 目标市场、差异化、资源配置 |
| 行业分析报告 | 招投标、痛点、竞品、政策 |
| 需求假设清单 | 待验证/已验证 |
| **Project Brief** | 项目简报 |
| **L1 一级业务域** | 顶层业务闭环，进入 BAM 追溯链 |

### 5.1 L1 定义示例

| L1 编号 | 一级业务域 | 说明 |
|---------|------------|------|
| L1-01 | 核心业务域 | 主流程闭环，如「线索→商机→成交」 |
| L1-02 | 支撑域 | 如「客户服务」「数据分析」 |

### 5.2 Project Brief 模板

- 项目背景、目标市场、价值主张
- 核心假设（痛频量价）
- L1 业务域列表
- 范围边界、排除项

**工具**：[Project Brief](../tools/Project-Brief.html) 结构化填写，支持从痛点画布复制痛频量价、从 BAM 导入 L1。

**检查清单**：五维洞察完成、战略要点明确、痛频量价有结论、**L1 已定义**
