## 一、培训体系总览

```
战略管理 ─────┬── 战略规划与执行
              ├── 竞争分析与洞察
              └── 目标分解与 OKR
                    ↓
数字化转型 ───┬── 转型战略与路径
              ├── 业务架构与流程
              └── 数据与智能化
                    ↓
业务分析 ─────┬── 需求与解决方案
              ├── 商业模式与 MVP
              └── 追溯与交付
```

| 模块 | 核心能力 | 对应 DIAL-BAM | 推荐资源 |
|------|----------|---------------|----------|
| **战略管理** | 洞察、战略规划、目标分解 | Discovery、Insight | 德鲁克、波特、华为战略到执行 |
| **数字化转型** | 转型路径、架构、成熟度 | Architecture | TAIITRE、TOGAF、德勤、华为 |
| **业务分析** | 需求、方案、追溯、交付 | 全流程 | BABOK、BAM、IPD、PMBOK |

## 二、战略管理培训

### 2.1 学习目标

- 掌握宏观环境分析（PESTEL、波特五力、SWOT）
- 理解战略从洞察到执行的闭环
- 能进行目标分解与战略解码

### 2.2 培训内容

| 主题 | 要点 | 工具/框架 |
|------|------|-----------|
| 战略洞察 | 行业分析、竞争格局、机会识别 | [洞察可视化](../tools/洞察可视化.html)、PESTEL、五力、SWOT |
| 战略规划 | 战略地图、平衡计分卡、目标设定 | [商业模式画布](../tools/商业模式画布.html)、战略地图 |
| 战略执行 | 战略解码、OKR、差距分析 | 华为战略到执行、[规划看板](../tools/规划看板.html) |
| 管理大师 | 德鲁克、波特、科特勒、查兰 | [指导文档/管理](指导文档/管理/) |

### 2.3 推荐学习路径

1. **入门**：阅读 [00 核心理念](00-核心理念.md)、[02 Discovery](02-Discovery.md)
2. **实践**：使用 [洞察可视化](../tools/洞察可视化.html)、[痛点画布](../tools/痛点画布.html)
3. **深化**：华为数字化转型、德鲁克/波特等管理经典

## 七、学习 · 实训 · 考试 · 认证 闭环

培训体系采用完整闭环：**学习 → 实训 → 考试 → 认证**。

| 环节 | 说明 |
|------|------|
| **学习** | 课程列表、章节学习、进度记录、按角色推荐 |
| **实训** | 动手任务：使用洞察可视化、痛点画布、BAM 追溯矩阵、BML 验证看板等完成实操 |
| **考试** | 单选题测验，检验核心理念与方法论掌握程度 |
| **认证** | 学习完成度 + 实训完成数 + 考试得分 达标后获得 DIAL-BAM 入门认证 |

认证条件（可配置）：学习完成度 ≥30%、完成 ≥1 个实训、考试得分 ≥60 分。

## 八、培训平台借鉴说明

本学习模块借鉴 **培训内容平台（微信和Web）** 的设计思路：

| 借鉴点 | 说明 |
|--------|------|
| **课程/章节结构** | 培训内容按课程组织，每课程含多节（文档/工具），支持按分类筛选 |
| **学习进度** | 本地存储记录已学习章节，支持「我的学习」查看进度 |
| **实训/打卡** | 实训任务清单，步骤可勾选完成（类似打卡） |
| **考试** | 测验题、得分记录、通过判定 |
| **认证/数字护照** | 聚合学习、实训、考试成果，达标获得认证 |

配置见 [学习培训-课程配置.json](../tools/学习培训-课程配置.json)，可扩展课程、实训、考试题与认证条件。

## 九、培训实施建议

1. **先理念后工具**：理解核心理念，再使用工具
2. **按阶段推进**：Discovery → Insight → Architecture → Launch 顺序学习
3. **结合项目实践**：用真实项目练习 BAM 追溯、规划看板、BML
4. **定期复盘**：利用 BML 验证看板记录学习与决策
5. **AI 辅助**：参考 [06 AI 增强与裁剪](06-AI增强与裁剪.md)，用 AI 辅助拆解与提示词
