> 5 分钟上手 DIAL-BAM 工具链。

📄 [← 方法论](01-方法论.md) | [工具应用](工具应用.md)

## 一、5 分钟快速路径

**目标**：5 分钟内完成首次 BAM 填写或洞察导出。

| 步骤 | 操作 | 工具 |
|------|------|------|
| 1 | 填写 PESTEL/五力/SWOT，点击「导出为 JSON」 | [洞察可视化](洞察可视化.html) |
| 2 | 填写痛频量价，点击「生成 BAM 初稿」→ 复制 AI 提示词 | [痛点画布](痛点画布.html) |
| 3 | 导入 JSON（或粘贴 AI 输出），编辑 L1/L2/REQ，点击「导出 JSON」 | [BAM 追溯矩阵](BAM-追溯矩阵.html) |

**可选**：从洞察「推送到痛点画布」可自动跳转并导入结论；BAM 导出后可导入 [规划看板](规划看板.html)。完整案例见 [企业案例：销售线索管理数字化](企业案例-销售线索管理数字化.md)。

## 二、启动工具

```bash
# 在项目根目录
npm run serve
```

访问 http://localhost:3789/tools 进入工具中心。

## 三、典型流程（新项目）

### 步骤 1：洞察（Discovery）

1. 打开 [洞察可视化](洞察可视化.html)
2. 填写 PESTEL、波特五力、SWOT
3. 点击「推送到痛点画布」→ 自动跳转痛点画布并提示导入；或「复制为 AI 提示词」/「生成 BAM 需求初稿」

### 步骤 2：痛点（Discovery）

1. 打开 [痛点画布](痛点画布.html)
2. 若从洞察跳转：确认导入洞察结论到「痛」字段
3. 填写痛频量价、需求假设清单
4. 点击「生成 BAM 初稿」

### 步骤 2b：Project Brief（可选）

1. 打开 [Project Brief](Project-Brief.html)
2. 填写项目背景、目标市场、价值主张、核心假设
3. 点击「从 BAM 导入 L1」或手动填写 L1 业务域
4. 导出 JSON 或 Markdown

### 步骤 2c：PRD（可选，Insight 阶段）

1. 打开 [PRD 模板](tools/PRD-模板.html)
2. 填写业务背景、目标用户、用户旅程、MVP
3. 点击「从 BAM 导入 L2」填充功能清单
4. 导出 JSON 或 Markdown

### 步骤 3：BAM 追溯矩阵（Architecture）

1. 打开 [BAM 追溯矩阵](BAM-追溯矩阵.html)
2. 若有 AI 生成的 JSON：点击「导入 JSON」上传
3. 或点击「加载示例」查看示例结构
4. 在「编辑」标签页增删改 L1/L2/REQ/Epic/Story/L3
5. 点击「导出 JSON」保存

### 步骤 4：规划看板（Architecture/Launch）

1. 打开 [规划看板](规划看板.html)
2. 点击「从 BAM 导入」，选择刚导出的 BAM JSON
3. 为 Epic/Story 设置短期/中期/长期、待办/进行中/完成

### 步骤 5：BML 验证（Launch）

1. 打开 [BML 验证看板](BML-验证看板.html)
2. 点击「+ 新增迭代」
3. 填写 Build、Measure、Learn、坚持/转向
4. 点击「从规划看板复制 Epic 列表」，粘贴到「关联 Epic/Story」

## 三、数据流速查

| 从 | 到 | 操作 |
|----|-----|------|
| 洞察 | 痛点画布 | 推送到痛点画布 → 从洞察导入 |
| 洞察 | BAM | 生成 BAM 初稿 → AI → 导入 JSON |
| 痛点画布 | BAM | 生成 BAM 初稿 → AI → 导入 JSON |
| BAM | Project Brief | 从 BAM 导入 L1 |
| BAM | PRD 模板 | 从 BAM 导入 L2 |
| BAM | 规划看板 | 从 BAM 导入 |
| 规划看板 | BML | 从规划看板复制 Epic 列表 |
| 各工具 | 交付包 | 交付包导出 → 导出 JSON |
