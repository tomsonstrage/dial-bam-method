# AI Prompt 与输出报告

> 将 DIAL-BAM 的**输入**与**方法论**整理为可输入外部 AI 工具（ChatGPT、Claude、通义等）的 Prompt 模板，并定义 AI 应返回的**输出报告**格式。

📄 [平台输入与数据入口](平台输入与数据入口.md) | [方法论](01-方法论.md) | [AI Prompt 生成器](../tools/AI-Prompt生成器.html)

---

## 一、Prompt 结构

输入外部 AI 的完整 Prompt 由三部分组成：

```
┌─────────────────────────────────────────────────────────────┐
│  Part 1: 角色与上下文（System / 前置说明）                     │
│  - 你是 DIAL-BAM 业务分析助手                                 │
│  - 核心理念、方法论框架、分析模型                              │
├─────────────────────────────────────────────────────────────┤
│  Part 2: 用户输入数据（User Input）                            │
│  - 洞察、痛点、BAM、规划等结构化数据                           │
│  - 或原始描述（行业、业务方向、待解决问题）                     │
├─────────────────────────────────────────────────────────────┤
│  Part 3: 输出要求（Output Specification）                     │
│  - 请按以下格式输出报告                                        │
│  - 报告结构、必含章节、格式约定                                │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、Part 1：角色与上下文（可复用）

以下内容可作为「系统提示」或 Prompt 前置，让 AI 理解 DIAL-BAM 框架：

```
【角色】你是 DIAL-BAM 业务分析助手，遵循「核心理念 → 方法论 → 工具」体系。

【核心理念】战略导向、流程分层、端到端追溯、闭环管理（参考华为）。

【方法论】DIAL 四阶段：
- Discovery：五维洞察（PESTEL、波特五力、SWOT）→ L1、需求假设
- Insight：战略规划、MVP、商业模式画布 → L2、PRD
- Architecture：业务分解 L1→L2→L3→L4，追溯链 REQ↔L1↔L2↔Epic↔Story↔L3↔L4
- Launch：任务拆解、BML 循环、坚持/转向决策

【分析模型】PESTEL、波特五力、SWOT、痛频量价、商业模式画布、BAM 追溯矩阵、BML。
```

## 三、Part 2：用户输入数据

### 3.1 输入来源

| 来源 | 格式 | 说明 |
|------|------|------|
| **洞察可视化** | JSON / 文本 | PESTEL、五力、SWOT 结构化数据 |
| **痛点画布** | JSON / 文本 | 痛频量价、需求假设清单 |
| **商业模式画布** | JSON / 文本 | 9 宫格 |
| **BAM 追溯矩阵** | JSON | L1/L2/L3/L4、REQ、Epic、Story |
| **规划看板** | JSON | Epic/Story 短中长期规划 |
| **原始描述** | 自然语言 | 行业、业务方向、待解决问题 |

### 3.2 输入示例（最小可用）

```
【业务背景】
- 行业：【如：企业服务 SaaS】
- 业务方向：【如：为中小制造企业提供设备管理数字化】
- 当前阶段：【Discovery / Insight / Architecture / Launch】

【已有输入】（可选，有则填写）
- 洞察/痛点/BAM 数据：（粘贴 JSON 或文本）
- 或：待解决问题描述
```

## 五、完整 Prompt 模板（复制即用）

将以下模板中的 `【用户输入】` 替换为实际数据后，粘贴到 ChatGPT、Claude 等：

```
【角色与上下文】
你是 DIAL-BAM 业务分析助手。核心理念：战略导向、流程分层、端到端追溯、闭环管理。
方法论：Discovery（洞察）→ Insight（战略）→ Architecture（业务分解）→ Launch（任务与 BML）。
分析模型：PESTEL、波特五力、SWOT、痛频量价、BAM 追溯链。

【用户输入】
【用户输入】

【输出要求】
请按「DIAL-BAM 业务分析报告」格式输出，包含：1) 洞察摘要；2) 需求与追溯；3) 短中长期规划；4) 风险与应对。若可生成 BAM 结构，请在报告末尾附上符合 BAM 导入指南的 JSON。
```

## 六、使用流程

```
1. 在工具中填写/导入数据（洞察、痛点、BAM 等）
     ↓
2. 打开 [AI Prompt 生成器](../tools/AI-Prompt生成器.html)，选择输入来源
     ↓
3. 点击「生成并复制 Prompt」
     ↓
4. 粘贴到外部 AI 工具（ChatGPT、Claude、通义等）
     ↓
5. 获取 AI 返回的报告
     ↓
6. 若报告含 JSON：在生成器中「粘贴 AI 输出」→「解析 JSON 并导入 BAM」→ 打开 BAM 追溯矩阵
```
