## 一、DIAL 流程

| 术语 | 英文 | 说明 |
|------|------|------|
| **Discovery** | 发现 | 洞察 + 需求调研，产出 L1、Project Brief |
| **Insight** | 洞察 | 方案 + MVP 定义，产出 L2、PRD |
| **Architecture** | 架构 | 业务分解、Epic/Story 划分、路线图 |
| **Launch** | 交付 | 任务拆解、BML 迭代、交付物 |

---

## 二、BAM 追溯链

| 术语 | 说明 | 产出阶段 |
|------|------|----------|
| **REQ** | 需求，可追溯的最小需求单元 | Discovery / Insight |
| **L1** | 一级业务域，顶层业务闭环 | Discovery |
| **L2** | 二级模块/页面，功能板块 | Insight |
| **L3** | 三级业务动作，用户可感知步骤 | Architecture |
| **L4** | 四级业务步骤，验收标准 | Launch |
| **Epic** | 功能史诗，介于 L2 与 Story 之间，1–N 周 | Architecture |
| **Story** | 用户故事，1–2 周可交付 | Architecture |
| **Task** | 任务，0.5–2 天可执行 | Launch |
| **AC** | 验收标准，Given/When/Then 或 L4 步骤 | Launch |

---

## 三、交付件

| 术语 | 说明 |
|------|------|
| **Project Brief** | 项目简报，含背景、目标市场、价值主张、L1 业务域、范围边界 |
| **PRD** | 产品需求文档，含业务背景、功能清单、用户旅程、MVP、非功能需求 |
| **交付包** | 汇总各工具数据的 JSON 包，支持导出/导入、完整性检查、选择性恢复 |

---

## 四、洞察与验证

| 术语 | 说明 |
|------|------|
| **PESTEL** | 宏观环境分析：政治、经济、社会、技术、环境、法律 |
| **波特五力** | 竞争分析：同业、供应商、购买者、替代品、新进入者 |
| **SWOT** | 内外部分析：优势、劣势、机会、威胁 |
| **痛频量价** | 需求验证四维：痛（强度）、频（频率）、量（规模）、价（付费意愿） |
| **MVP** | 最小可行产品，用于验证核心假设 |
| **BML** | Build-Measure-Learn，构建→测量→学习→坚持/转向 |
