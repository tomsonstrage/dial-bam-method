# 平台输入与数据入口

> 定义 DIAL-BAM 体系的**数据输入**来源、入口及与工具/方法论的衔接。核心理念 → 方法论 → 工具 的「输入层」设计。

📄 [核心理念](00-核心理念.md) | [方法论](01-方法论.md) | [工具应用](工具应用.md)

---

## 一、输入体系总览

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     DIAL-BAM 平台输入层                                  │
├─────────────────────────────────────────────────────────────────────────┤
│  文件上传入口              │  资料库检索入口           │  跨工具数据流   │
│  ├─ JSON（BAM、规划、洞察）  │  ├─ 方法论文档（00-06）    │  ├─ 洞察 → 痛点  │
│  ├─ Excel（需求/L1/L2）     │  ├─ 参考框架、指导文档     │  ├─ 痛点 → Project Brief、BAM │
│  └─ 其他格式（规划中）      │  └─ 全文/关键词检索       │  ├─ BAM → Project Brief、PRD、规划 │
│  └─ 各工具 → 交付包导出 │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│  核心理念 → 方法论 → 分析模型 → 工具（洞察/痛点/PB/PRD/BAM/规划/BML/交付包）  │
└─────────────────────────────────────────────────────────────────────────┘
```

## 二、输入类型与入口

### 2.1 原始资料（外部输入）

| 类型 | 说明 | 当前入口 | 建议用途 |
|------|------|----------|----------|
| **行业报告** | 政策、市场、竞品分析 | 手动摘录到洞察/痛点 | 支持 PDF/Word 上传（规划中） |
| **访谈记录** | 用户访谈、需求调研 | 手动整理到需求假设 | 支持 Word/Markdown 上传（规划中） |
| **招投标数据** | 采购需求、标书 | 手动整理到 BAM | 支持 Excel 导入（已支持） |

### 2.2 结构化数据（工具间输入）

| 格式 | 支持工具 | 说明 |
|------|----------|------|
| **JSON** | BAM、规划、洞察、痛点、Project Brief、PRD、商业模式画布、BML、交付包导出 | 导入/导出，工具间数据流转；格式见 [Schema](../tools/schema/README.md) |
| **Excel** | BAM 追溯矩阵、规划看板 | 需求清单、L1/L2 等表格数据导入 |

### 2.3 方法论文档（资料库）

| 来源 | 内容 | 检索方式 |
|------|------|----------|
| **docs/** | 00-06 方法论、核心理念、术语表、FAQ | [文档阅读](tools/文档阅读.html) 选择 + 关键词检索 |
| **指导文档/** | 华为、TOGAF、ThoughtWorks、PMBOK 等 | 文档阅读 + 指导文档索引 |
| **参考框架索引** | PESTEL、五力、SWOT、BIZBOK、IPD 等 | 参考框架索引.md |

### 2.4 跨工具数据流

| 流向 | 说明 |
|------|------|
| **洞察可视化 → 痛点画布** | 洞察结论作为痛点分析输入 |
| **痛点画布 → Project Brief** | 「从痛点画布复制痛频量价」填充核心假设 |
| **痛点画布 → BAM 追溯矩阵** | 「痛点画布生成初稿」生成 BAM 初稿 |
| **BAM → Project Brief** | 「从 BAM 导入 L1」填充 L1 业务域 |
| **BAM → PRD 模板** | 「从 BAM 导入 L2」填充功能清单 |
| **Project Brief → BAM** | 「从 Project Brief 导入 L1」 |
| **BAM 追溯矩阵 → 规划看板** | 「从 BAM 导入」填充 Epic/Story 规划 |
| **各工具 → 交付包导出** | 汇总导出、完整性检查、导入恢复 |

## 三、各工具输入入口明细

| 工具 | 输入方式 | 支持格式 |
|------|----------|----------|
| **洞察可视化** | 表单填写、**导入 JSON**、localStorage | 导入/导出 JSON、TXT |
| **痛点画布** | 表单填写、**导入 JSON**、从洞察导入、localStorage | 导入/导出 JSON、TXT |
| **Project Brief** | 表单填写、**导入 JSON**、痛点复制、BAM 导入 L1 | 导入/导出 JSON、MD |
| **商业模式画布** | 表单填写、**导入 JSON**、localStorage | 导入/导出 JSON、TXT |
| **PRD 模板** | 表单填写、**导入 JSON**、BAM 导入 L2 | 导入/导出 JSON、MD |
| **BAM 追溯矩阵** | 预置 JSON、文件导入、痛点初稿、Project Brief 导入 L1、手动编辑 | JSON、Excel |
| **规划看板** | BAM 导入、文件导入、手动编辑 | JSON、Excel |
| **BML 验证看板** | 表单填写、**导入 JSON**、localStorage | 导入/导出 JSON、TXT |
| **交付包导出** | 汇总各工具 localStorage、文件导入 | 导出/导入 JSON |
| **文档阅读** | 下拉选择、URL 参数、关键词检索 | Markdown（docs/） |

**规范文档**：各模块输入输出字段、格式详见 [各模块输入输出规范](../tools/各模块输入输出规范.md)。**模板**：各工具提供「下载模板」，填写数值后导入，见 [输入输出模板](../tools/templates/README.md)。

## 四、文件格式说明

### 4.1 JSON 导入

- **BAM**：需符合 [BAM 导入指南](../tools/BAM-导入指南.md) 中的数据结构（meta、L1、L2、L3、requirements、epics、stories）
- **规划看板**：需含 `epics`、`stories` 及 `horizon`、`status` 等字段
- **洞察、痛点、BMC、Project Brief、PRD、BML**：字段规范见 [各模块输入输出规范](../tools/各模块输入输出规范.md)

### 4.2 Excel 导入

- **BAM**：按 Sheet 名称（L1、L2、L3、requirements、epics、stories）组织，首行为表头，详见 [BAM 导入指南](../tools/BAM-导入指南.md)
- **规划看板**：首行表头含 epic_id、epic_name、epic_horizon、epic_status、story_id、story_name、story_horizon、story_status，每行一个 Story，同 Epic 多行合并

## 五、资料库检索

| 能力 | 说明 |
|------|------|
| **文档选择** | 按分类（快速开始、核心理念、DIAL 阶段等）选择文档 |
| **关键词检索** | 在文档列表中按标题/文件名搜索，快速定位 |
| **当前文档内搜索** | 在已加载文档内高亮匹配关键词 |
| **全文检索** | 规划中：跨文档全文搜索 |
