## 四、工具数据流

| 流向 | 说明 |
|------|------|
| **洞察可视化 → 痛点画布** | 洞察结论作为痛点分析输入 |
| **痛点画布 → BAM 追溯矩阵** | 「痛点画布生成初稿」生成 BAM 初稿 |
| **痛点画布 → Project Brief** | 「从痛点画布复制痛频量价」填充核心假设 |
| **BAM → Project Brief** | 「从 BAM 导入 L1」填充 L1 业务域 |
| **BAM → PRD 模板** | 「从 BAM 导入 L2」填充功能清单 |
| **商业模式画布 → BAM** | L2 输入 |
| **BAM → 规划看板** | 「从 BAM 导入」填充 Epic/Story |
| **BML 验证 → 痛点画布** | 坚持/转向可反馈至痛点重新验证 |
| **各工具 → 交付包导出** | 汇总导出、完整性检查 |

详见 [业务流可视化](../tools/业务流可视化.html) 的「工具与数据流」标签页。

## 六、使用建议

1. **先明确理念**：当前卡在战略？流程分层？追溯？闭环？
2. **再选工具**：按上表选对应工具
3. **工具不足时**：用文档中的模板（02–05 各阶段含模板）
4. **企业诊断**：使用 [业务流可视化](../tools/业务流可视化.html) 按「企业诊断流程」引导
