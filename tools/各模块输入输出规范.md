## 三、模块间数据流与兼容

| 流向 | 源模块输出 | 目标模块输入 | 字段映射 |
|------|------------|--------------|----------|
| 洞察 → 痛点 | 洞察 JSON | 痛点「从洞察导入」 | 洞察结论 → pain |
| 痛点 → BAM | 痛点 JSON / AI 提示词 | BAM 导入 JSON | 需求假设 → requirements |
| BAM → Project Brief | BAM.L1 | Project Brief.L1 | 直接映射 |
| BAM → PRD | BAM.L2 | PRD.functions | L2 → functions |
| BAM → 规划 | BAM.epics/stories | 规划.epics | 直接映射 |
| 规划 → BML | 规划 Epic/Story ID | BML.scope | 复制 ID 列表 |

## 四、输入输出模板

各模块均有**模板 JSON**，定义输入/输出结构。使用方式：

1. **下载模板**：在工具中点击「下载模板」，获取空结构
2. **填写数值**：按模板字段填写具体内容
3. **导入**：选择填写好的 JSON 文件导入
4. **导出**：工具按模板结构导出当前数据

模板文件位于 `tools/templates/`，详见 [templates/README.md](templates/README.md)。

---

## 五、UI 规范建议

各模块应统一提供：

- **下载模板**：`下载模板` 按钮，获取空结构 JSON
- **导入**：`导入 JSON` 按钮 + `<input type="file" accept=".json">`
- **导出**：`导出 JSON`、`导出文本`（或 `导出 Markdown`，视模块而定）
- **跨工具**：有上下游关系的，提供「从 XX 导入」快捷入口
