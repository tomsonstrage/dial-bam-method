# 各模块输入输出模板

> 各工具的**输入/输出模板**，定义数据结构。用户可下载模板、填写数值、导入；工具导出时按此结构输出。

## 使用方式

1. **下载模板**：在对应工具中点击「下载模板」，获取空结构 JSON
2. **填写数值**：按模板中的字段填写具体内容
3. **导入**：在工具中点击「导入 JSON」，选择填写好的文件
4. **导出**：工具按模板结构导出当前数据，可直接再次导入或分享
