工具与数据流

  • 洞察可视化 → 痛点画布（洞察结论输入）
  • 痛点画布 → Project Brief（痛频量价）、BAM（生成初稿）
  • BAM ↔ Project Brief（L1 互导）、BAM → PRD（导入 L2）
  • 商业模式画布 → BAM（L2 输入）
  • BAM → 规划看板（导入 Epic/Story）
  • BML 验证 → 坚持/转向可反馈至痛点重新验证
  • 交付包导出：汇总各工具数据，含完整性检查

企业诊断与优化流程

  • 入场：访谈 + 五维洞察工作坊 + 痛点收集
  • Discovery：洞察可视化、痛点画布 → L1、Project Brief
  • Insight：商业模式画布、差距分析 → L2、PRD、MVP
  • Architecture：BAM、规划看板 → 短中长期路线图
  • Launch：任务拆解、BML、坚持/转向
  • 顾问交付物：诊断报告、战略要点、路线图、BAM、BML 记录
